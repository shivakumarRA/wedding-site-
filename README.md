# Sneha & Venkateswarlu — Wedding Invitation (Girl's Side)

Telugu & English wedding invitation website for **Chi. La. Sow. Sneha** & **Chi. Venkateswarlu**, created for the Bride's (Girl's) Family.

Built with Next.js 16 (App Router), Tailwind CSS v4, Framer Motion, and Lucide React.

## Quick Start
```bash
npm run dev                 # http://localhost:3000
npm run build && npm start  # production
```

## Features
- **Girl's / Bride's Side Centered**:
  - Primary names: Chi. La. Sow. Sneha with Chi. Venkateswarlu (చి॥ ల॥ సౌ॥ స్నేహ మరియు చి॥ వెంకటేశ్వర్లు)
  - Monogram: "S & V" ("స్నే ♥ వెం")
  - Solicitation: Invitation on the auspicious occasion of the marriage of their second daughter (ద్వితీయ పుత్రిక)
  - Invitation By: Sri Marapangu Nagarjuna & Chilakamma (మారపంగు నాగార్జున – చిలకమ్మ), Kudali Village, Mothey Mandal, Suryapet District
  - Couple Section: Bride featured prominently with Groom's family details (Only son of Nukapangu Thirapaiah & Thirapamma)
- **Bilingual**: Toggle between English and Telugu (తెలుగు) anytime.
- **Audio & Animations**: Traditional temple gate doors opening, background wedding music, kalasam and marigold animations.
- **Auspicious Timings (Sumuhurtham)**: Sunday, 22 November 2026 at 11:22 AM (Aswini Nakshatram, Dhanassu Lagnam), Lunch at 12:00 PM at P.V. Function Hall, Nayakangudem.
- **Interactive Tools**: Live countdown timer, Add to Calendar (.ics), WhatsApp invitation sharing, Google Maps directions, and downloadable A5 PDF invitation.
- **Family Side Switcher**: Switch between Bride's Family and Groom's Family invitations.
